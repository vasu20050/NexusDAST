🚀 Quick Start

1. Clone Repository

git clone https://github.com/vasu20050/NexusDAST.git cd NexusDAST

2. Install Dependencies

cd backend pip install -r requirements.txt python -m playwright install

3. Create Configuration

# Edit config.yml with your target URL python -m scanner.cli --config ../config.yml

4. View Results

# Open scan_report.html in your browser start scan_report.html # Windows open scan_report.html # macOS xdg-open scan_report.html # Linux
💡 Tip: Check the documentation folder for detailed setup guides for your platform.

ℹ️ About NexusDAST

Project Overview

NexusDAST is an advanced, production-ready web application vulnerability scanner designed to identify critical security weaknesses in modern web applications. Built with security professionals and DevOps teams in mind, it provides intelligent crawling, comprehensive vulnerability detection, and professional reporting.

Browser Automation: Playwright
HTTP Client: requests
