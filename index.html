Detection Methods

SQL Injection

Error-based pattern matching with database error detection and blind SQL injection testing.

Cross-Site Scripting

Reflection analysis and DOM-based XSS detection across multiple payload vectors.

Template Injection

Server-side (SSTI) and client-side (CSTI) template injection expression detection.

Authorization Issues

Broken object level access (BOLA) through intelligent ID enumeration and fuzzing.

Security Headers

Missing security headers detection with configuration recommendations.

CSRF Protection

Token presence verification and CSRF protection validation across state-changing operations.

Quick Start Guide

Get Up and Running in 4 Steps

1. Clone Repository

git clone https://github.com/vasu20050/NexusDAST.git

2. Install Dependencies

cd backend && pip install -r requirements.txt

3. Configure

Edit config.yml with your target URL and preferences

4. Run Scanner

python -m scanner.cli --config config.yml
